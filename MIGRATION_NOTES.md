## Task mapping and constraints

- Turbo orchestrates lint, typecheck, test, clean, format, and available dev/build tasks.
- Apps have real dev/build tasks. Source-only packages have no standalone server or emitted build artifacts, so no placeholder dev/build scripts were added.
- packages/assets is canonical data, not a workspace package because it has no package manifest.
- The .qa archive had concurrent user changes, including a separate commit that removed its tracked copies. No restructuring change attempted to restore or remove that archive.
